# Raw Sources

Use this area for source materials that feed the wiki.

## Structure

- `originals/`: immutable source files
- `normalized/`: markdown or text derived from originals
- `assets/`: downloaded images or attachments

## Guidance

- Place binary originals under the matching `originals/` subfolder.
- Place markdown converted versions under the matching `normalized/` subfolder.
- Prefer ingesting from normalized markdown when available.
